    How Opulse fits¶

    Opulse starts from the classical idea that functions are built from simpler operations by composition and controlled recursion, and turns it into generated definitions whose values, dependencies, and derivation steps can be checked. AM, HR, and DreamCoder studied how useful concepts are invented and reused; learning theory, how rules are inferred from examples and queries; cognitive and synthetic task research, whether learned rules transfer to new combinations. Opulse lets these questions be tested with fresh, executable rules.

    Ideas Opulse can draw on¶

    1. Active rule learning: Use Angluin style membership queries and counterexamples. Measure query count and equivalence.
    2. Useful concept invention: Use AM, HR, DreamCoder, and Stitch criteria: reuse, held out success, solution compression, and newly supported laws. See concept discovery.
    3. Propagation after edits: Use RippleEdits and truth maintenance to score the affected dependency closure and unaffected controls. See edit propagation.
    4. Systematic composition splits: Use SCAN, COGS, and PCFG SET to distinguish new atoms, compositions, positions, and depth.
    5. Curriculum with known prerequisites: Compare staged and mixed exposure at equal data budgets, after Turing, Elman, and Bengio. See prerequisite order.
    6. Verified process supervision: Following bAbI and CLEVR as diagnostic task families, report interpreter checked rewrites and the first error location as separate outcomes. See process reward.
    7. Abstraction quality beyond recovery: Following LILO, test whether a meaningful name or short explanation improves later use of an invented operator. See concept discovery.
    8. Learning curves for rule use: Separate repeated inputs, new inputs for familiar operators, and new compositions, informed by ACT R and grokking studies.
    9. Resource aware recursive tasks: Measure unfoldings, output growth, execution cost, and prompt length separately, inspired by Grzegorczyk’s function classes.
    10. Self generated task ledger: Borrow PowerPlay’s retention check and Absolute Zero’s executable feedback. Evaluate every round on untouched rule libraries.
