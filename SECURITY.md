# Security policy

Please report a suspected security vulnerability privately through [GitHub security advisories](https://github.com/mkj69/opulse/security/advisories/new). On the repository's Security page, choose **Report a vulnerability**. Include the affected version, steps to reproduce, possible impact and any proof of concept you can share safely.

Please keep vulnerability details out of public issues and discussions while the report is being reviewed. GitHub's private reporting form is available when private vulnerability reporting is enabled for the repository.
