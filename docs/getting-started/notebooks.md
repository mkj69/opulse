# Tutorial notebooks

Run each notebook from the repository checkout after installing `opulse`. The [glossary](../glossary.md) explains terms used in the examples.

* [Grow your first world](https://github.com/mkj69/opulse/blob/main/examples/notebooks/01_grow_your_first_world.ipynb) registers an atom, grows operators, and describes a definition.
* [Derivations at any granularity](https://github.com/mkj69/opulse/blob/main/examples/notebooks/02_derivations_at_any_granularity.ipynb) compares checked reductions with different known operator sets.
* [Benchmark a model](https://github.com/mkj69/opulse/blob/main/examples/notebooks/03_benchmark_a_model.ipynb) builds and checks tasks, then grades a fixed stub reply.
* [One factor at a time](https://github.com/mkj69/opulse/blob/main/examples/notebooks/04_one_factor_at_a_time.ipynb) changes the result base and compares paired record statistics.
* [RL rewards](https://github.com/mkj69/opulse/blob/main/examples/notebooks/05_rl_rewards.ipynb) compares outcome, step, and progress values for sample completions.
