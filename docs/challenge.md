# Learn this tiny world

Choose an angle, then choose a mode. **Compute** follows rules to a result. **Invert** finds an unknown input. **Decide** tests a claim. **Describe** connects rules with plain language. **Induce** infers a rule from examples or carries its structure to another world. **Create** builds a rule or expression for a goal.

In Compute, Expert, Master, and Legend include longer [derivations](glossary.md), or checked step sequences. In Describe, match a rule with its description or write a rule from a description. In Hit the target, combine the given numbers with allowed operators; use each number at most once.
